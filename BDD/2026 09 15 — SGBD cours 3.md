### Définitions

- **SQL** : language permettant de donner des ordres au SGBDR
- **ORM**
- « # » ou « $ » pour les **clés étrangères** (convention)

### CREATE TABLE

exo 1 :

```sql
CREATE TABLE Personel (
    numero INT NOT NULL,
    nom VARCHAR(255) NOT NULL,
    prenom VARCHAR(255) NOT NULL,
    ville VARCHAR(255) NULL,
    salaire FLOAT(8,2) NOT NULL DEFAULT 100,
    date_entree DATE NOT NULL,
    sexe char(1) NOT NULL DEFAULT 'h'
);
```

exo 2 :

```sql
CREATE TABLE Client (
    client_id INT NOT NULL UNIQUE,
    prenom CHAR(15),
    nom CHAR(20) NOT NULL,
    rue CHAR(25),
    ville CHAR(20),
    Code_postal CHAR(5),
    tel CHAR(13)
);
```

### ALTER TABLE

exo 3 :
