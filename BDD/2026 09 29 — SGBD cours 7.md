Lister pilotes et vols qu’ils ont effectués

```sql
SELECT * FROM pilote INNER JOIN vol 
WHERE pilote.numpil = vol.numpil;
```

Lister tous les pilotes et éventuellement les vols effectués

```sql
SELECT * FROM pilote LEFT OUTER JOIN vol 
USING(numpil);
```

Lister tous les pilotes et les avions qu’ils ont pilotés

```sql
SELECT pilote.nompil, avion.nomav FROM pilote 
INNER JOIN vol USING(numpil)
INNER JOIN avion USING(numav);
```

Lister les noms de pilotes qui ont assuré un vol à partir d’une ville identique à leur ville de naissance

```sql
SELECT nompil FROM pilote
INNER JOIN vol USING(numpil)
WHERE pilote.ville = vol.ville;
```

Lister noms avions qui ont été pilotés par un pilote gagnant plus de 2000e

```sql
SELECT nomav FROM pilote 
INNER JOIN vol USING(numpil)
INNER JOIN avion USING (numav)
WHERE pilote.salaire > 2000.0;
```

Lister nombre d'avions

```sql
SELECT COUNT(numavion) FROM avion;
```

Lister salaire moyen des pilotes;

```sql
SELECT AVG(salairepil) FROM pilote;
```

Lister le salaire le plus petit et le plus grand des pilotes

```sql
SELECT MIN(salairepil) FROM pilote;
SELECT MAX(salairepil) FROM pilote;
```

Lister le nombre total des vols de chaque pilote;

```sql
SELECT numpil, COUNT(numvol) FROM pilote
INNER JOIN vol USING(numpil)
GROUP BY (numpil);
```
