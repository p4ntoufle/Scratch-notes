Personnes numéro 1 3 5 entrées entre 1er mars 2007 et 30 avril 2007 :

Écriture simple :

```sql
SELECT * 
FROM personne 
WHERE (numero=1 OR numero=3 OR numero=5) AND (dateEntree >= `2007-03-01` AND dateSortie =< `2007-04-30`);
```

Écriture étendue :

```sql
SELECT * 
FROM personne 
WHERE numero NOT IN (1,3,5) AND dateEntree NOT BETWEEN `2007-03-01` AND `2007-04-30`;
```

Commence par b et termine par e :

```sql
SELECT numero, nom, prenom, ville 
FROM personne 
WHERE nom LIKE "b%" OR nom LIKE "%e";
```

"ad" dans le mot : 

```sql
SELECT * 
FROM personne 
WHERE nom LIKE "%ad%";
```

personne dont le nom contient un "m" en 3ème caractère :

```sql
SELECT * 
FROM personne 
WHERE nom LIKE "__m%";
```

personne dont la ville n’est pas renseignée (nulle) :

```sql
SELECT * 
FROM personne 
WHERE ville IS NULL;
```

l’inverse :

```sql
SELECT * 
FROM personne 
WHERE ville IS NOT NULL;
```
