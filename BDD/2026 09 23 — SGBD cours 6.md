pilotes et vols et selection pour rétablir la cohérence et projection

```sql
SELECT pilote.numpil, nompil, numvol FROM pilote CROSS JOIN vol WHERE pilote.numpil = vol.numpil
```

Jointure ++naturelle++

```sql
SELECT * FROM pilote
NATURAL JOIN vol
NATURAL JOIN avion;
```

Jointure externe

```sql
SELECT … FROM … left|right|full outer join … critèreDeJointure;
```

Tous les pilotes et éventuellement leurs vols :

```sql
SELECT * FROM pilotes LEFT OUTER JOIN vols ON pilote.numpil = vol.numpil;
```

Afficher d’abord les colonnes de vols et pilote :

```sql
SELECT * FROM pilotes RIGHT outer join vols ON pilote.numpil = vol.numpil;
```

COUNT(numero) as nombrePersonnes,
COUNT(ville) as nombreVilles,
COUNT(distinct ville) as villesDiff FROM personne;

FROM personne
GROUP BY ville
HAVING totalDesSalaires > 2000;
